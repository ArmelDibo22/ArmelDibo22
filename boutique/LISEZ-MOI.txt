DÉMARRER EN 5 COMMANDES (Node.js 22.5 ou plus récent requis)
--------------------------------------------------------------------------------

  cd boutique
  npm ci --no-audit --no-fund          # installe les 6 dépendances
  cp .env.example .env                 # puis éditer .env (2 secrets à générer)
  npm run migrate && npm run seed      # crée la base et la configuration de base
  npm start                            # boutique sur http://localhost:3000

  Boutique        http://localhost:3000
  Administration  http://localhost:3000/admin
                  identifiants = ADMIN_EMAIL / ADMIN_PASSWORD du fichier .env

  Le catalogue réel démarre VIDE par conception : aucun article n'est inventé.

À SAVOIR AVANT TOUTE MISE EN LIGNE
--------------------------------------------------------------------------------

  * Aucun service payant n'a été souscrit, aucune boutique n'est publiée.
  * Aucune information d'établissement n'est inventée : adresse, horaires, logo,
    tarifs de livraison et textes légaux restent à confirmer (liste « Mise en
    route » du tableau de bord, 1 information sur 8 confirmée aujourd'hui).
  * Les identifiants marchands Mobile Money sont vides : tant qu'ils ne sont pas
    fournis par la passerelle, les moyens correspondants restent « non configurés »
    et le paiement en espèces (retrait ou livraison) fonctionne pleinement.
  * En production : NODE_ENV=production, PAYMENT_SIMULATION_ENABLED=false,
    APP_SECRET et PAYMENT_WEBHOOK_SECRET générés, mot de passe administrateur
    changé. L'application refuse de démarrer avec un secret faible.
  * Sauvegarde quotidienne recommandée : `npm run backup` (base) ou
    `npm run backup:full` (base + photos), puis copie HORS du serveur.
